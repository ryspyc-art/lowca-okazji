# Łowca Okazji

Responsywna, statyczna strona demonstracyjna przygotowana pod GitHub Pages.

## Pliki
- `index.html` — struktura strony
- `style.css` — wygląd i układ responsywny
- `app.js` — wyszukiwanie, kategorie, sortowanie i ulubione

## Publikacja na GitHub Pages
1. Otwórz repozytorium `ryspyc-art/lowca-okazji`.
2. Wybierz **Add file → Upload files**.
3. Wgraj trzy pliki strony: `index.html`, `style.css`, `app.js` (README może pozostać).
4. Zatwierdź zmiany przyciskiem **Commit changes**.
5. W **Settings → Pages** ustaw publikację z gałęzi `main`, katalog `/ (root)`.

## Ważne
Katalog ofert zawiera wyłącznie dane demonstracyjne. Strona nie pobiera jeszcze aktualnych cen ani produktów ze sklepów. Do uruchomienia rzeczywistego agregatora potrzebne będzie legalne źródło danych (np. API afiliacyjne/partnerskie), identyfikatory wydawcy i konfiguracja linków afiliacyjnych. Nie należy prezentować danych demonstracyjnych jako aktualnych promocji.
